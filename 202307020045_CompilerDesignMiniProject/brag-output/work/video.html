A compiler works in five phases
This mini compiler is written in C, and it shows you every phase.
PHASE 01
Lexical analysis
Reads characters and groups them into tokens.
Spaces and comments are thrown away.
It also catchesx = 10 @ 29abc/* unclosed
PHASE 02
Syntax analysis
Checks the grammar and builds a syntax tree.
Recursive descent: one C function per rule
add → mul { '+' mul } mul → unary { '*' unary }
* is parsed one level deeper,
so it binds tighter than +.
PHASE 03
Semantic analysis
Does it make sense? Names, scopes and types.
